# List of Supported LLM Services

- Anthropic
- Ollama
- OpenAI
- Google
- xAI
- Groq
- DeepSeek

If you cannot find your provider in this list, it is most likely compatible with the OpenAI API format. In this case, try using the OpenAI or xAI service configuration.

See the [Model and Service Selection Guide](model-and-service-selection.md) for more information.
