# The SVI solution Technical Description

## The main description of SVI (Structured VIbe coding)

The main idea behind the solution is considering your project as a set of different isolated parts working together. Each part is generated by AI separately on other parts thus saving context and getting more reproducible inference results.

Each part can have its own specification (prompt), it can include other specifications (other promtps or any other files can be added to context, aka imported), it can depend on other parts of code.
