# CONTRIBUTING to SVI

Thank you for your interest in contributing to SVI!

We welcome all contributions: bug fixes, features, documentation improvements, and ideas.

---

## 1. Clone the repository

Start by cloning the project:

```bash
git clone https://github.com/avrmsoft/svi.git
cd svi
```

## 2. Install dependencies

We use pnpm:

```bash
pnpm install
```

## 3. Build the project

```bash
pnpm build
```

4. Run tests

Before submitting changes, make sure all tests pass:

```bash
pnpm test
```

If your change affects functionality, please also add new tests.

## 5. Development

For active development you can run:

```bash
pnpm dev
```

## 6. Make your changes

Create a new branch for your feature or fix:

```bash
git checkout -b feature/my-new-feature
```

## 7. Submit a Pull Request

When you're done - push your branch

```bash
git push origin feature/my-new-feature
```

Open a Pull Request on GitHub
Describe clearly what your change does and why
